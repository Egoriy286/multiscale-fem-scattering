# Увеличение физического FEM-датасета

Новый профиль: **1000 сред × 8 направлений = 8000 снимков на частотную полосу**, всего **16000 снимков**. Ранее было 48×4=192 снимка на полосу; увеличение составляет примерно 41.67 раза. Запрос охватывает генерацию физических данных; обучение, SVD-диагностика и новые сравнительные метрики нейросетей отдельно не запускались в рамках этого увеличения.

| Параметр | Низкая полоса | Высокая полоса |
| --- | --- | --- |
| k | [1,2] | [4,8] |
| Каталог данных | `data/low_frequency_1000x8` | `data/high_frequency_1000x8` |
| Будущий каталог моделей | `runs/low_frequency_1000x8` | `runs/high_frequency_1000x8` |
| Среды / направления / снимки | 1000 / 8 / 8000 | 1000 / 8 / 8000 |
| Train среды / снимки | 670 / 5360 | 670 / 5360 |
| Val среды / снимки | 170 / 1360 | 170 / 1360 |
| Test среды / снимки | 160 / 1280 | 160 / 1280 |

Обе конфигурации используют seed=2026, split fractions=(.67,.17,.16), h=0.1 и coarse grid 4×4. Параметры геометрии и распределения физических контрастов сохранены. Все восемь направлений одной среды принадлежат одному split; соответствующие среды между частотными полосами должны сохранять split. Увеличение числа снимков не означает уменьшение шага сетки.

Параметры доступны в [low-band config.json](../data/low_frequency_1000x8/config.json) и [high-band config.json](../data/high_frequency_1000x8/config.json). Сводки фактических counts и hashes сохраняются в [low-band dataset_info.json](../data/low_frequency_1000x8/dataset_info.json) и [high-band dataset_info.json](../data/high_frequency_1000x8/dataset_info.json).

## Что сохранено отдельно

Датасеты `data/low_frequency` и `data/high_frequency`, шесть pilot моделей в `runs/low_frequency`/`runs/high_frequency` и [измеренный pilot report](local_results.md) остаются артефактами прежнего профиля 48×4. Их показатели не переносятся на увеличенный набор. Новые notebook/CLI defaults обращаются к каталогам с суффиксом `_1000x8`; первое отдельное выполнение training ячеек создаст новые модели. При повторном вызове cache требует совпадения config и dataset fingerprint. `retrain=True` означает свежее обучение; автоматического продолжения старого training run нет.

Генерация использует заранее выделенные массивы, сохраняя точные DG0 коэффициенты и комплексные поля без накопления полного списка копий. Запись готовых файлов выполняется атомарно; прогресс генерации не равнозначен подтверждению целостности итоговых архивов.

## Фактические результаты генерации и проверки

Обе полосы сгенерированы локально и повторно прочитаны с диска. Машинный протокол: [dataset_expansion.json](dataset_expansion.json). Все хеши загруженных массивов совпали с хешами исходных массивов после генерации.

| Набор | u_scat | DG0 A,n | Архив, MiB | Генерация и сохранение, с |
|---|---|---|---:|---:|
| low_frequency_1000x8 | [8000, 3221] complex128 | [8000, 6280] float64 | 387.87 | 142.34 |
| high_frequency_1000x8 | [8000, 3221] complex128 | [8000, 6280] float64 | 388.16 | 100.54 |

Время включает генерацию, сжатую запись и создание manifest; зависит от фоновой нагрузки локальной VM. Геометрия каждой полосы: 3221 CG1-узел и 6280 треугольников. Все поля конечны, A,n,k положительны; на каждую из 1000 сред приходятся ровно восемь равномерно разнесённых направлений. Train/val/test counts подтверждены: 5360/1360/1280, целые medium IDs не пересекаются между splits.

Совпадение между low/high подтверждено SHA256 для координат, connectivity, cell tags, кругов, A,n, исходных DG0 A_cells/n_cells, направлений, medium IDs и split. Хеши k и решений различаются, как требуется.

Для каждого из трёх splits в каждой полосе выбран пример с максимальным k и повторно решена сохранённая FEM-задача. Во всех шести проверках relative FEM L2 difference равна 0; максимальный relative linear residual — 2.893e-14.

**28 тестов прошли.** Проверены независимые UFL-формы, отсутствие утечки сред, точность DG0/complex128 roundtrip и новый путь генерации без повторной загрузки архива. Прежние два пилотных набора и шесть обученных моделей сохранены.

Обновлены defaults в settings.py, CLI и восемь notebooks. Старые outputs в обновлённых notebooks очищены; новый Dataset notebook выполнен на 8000 low-band снимках. Обучение и новые показатели качества нейросетей на расширенном наборе в этот запрос не входили; для них используются отдельные каталоги моделей.

## Пределы интерпретации

Новые 8000 снимков на полосу ещё не дают новых измерений точности модели. В исходном SVD pilot test FEM L2 была около 0.6858 при POD reconstruction error около 0.02668; ни эта ошибка, ни исходные checkpoints не характеризуют будущий fit на 1000 средах.

Для высокой полосы h=0.1 не изменён. В pilot наблюдалась разница с уточнённой FEM-сеткой примерно 11–15%. Увеличение числа сред не исправляет эту ошибку дискретизации; для вывода о физической точности по-прежнему нужна отдельная mesh-refinement проверка. Будущее сравнение должно отдельно показывать полный neural test из 1280 снимков и paired classical subset, не смешивая разные множества в одной средней.
