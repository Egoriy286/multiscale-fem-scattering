# Статичная физическая среда: спецификация и проверка

В текущем профиле неизменны геометрия, активные включения, A,n в узлах и точные DG0 материалы на ячейках. Изменяются только параметры падающей волны `(k,θ)`. Это новая постановка с отдельными каталогами; прежние variable-medium и pilot данные сохраняются.

## Как зафиксирован материал

`StaticDatasetConfig` задаёт `fixed_medium_id=0`, `seed=2026`, прежние `active_range=(3,10)`, `a_range=(.6,.9)` и `n_range=(1.5,3.)`. `generate_static_dataset` воспроизводит материал **среды 0 прежнего dynamic генератора**: сначала делает тот же начальный RNG draw частоты, затем выбирает активные круги и их контрасты. Начальная частота не используется как единственная частота нового эксперимента. Воспроизведение последовательности RNG сохраняет прежний материал вместо нового случайного draw.

Фон A=n=1; значения внутри каждого активного включения выбираются один раз. Набор контрастов не усиливается. Обе частотные полосы используют один физический материал. Для всех строк `medium_id=0`.

## Частоты, направления и split

| Параметр | Low-band | High-band |
| --- | --- | --- |
| Частотная полоса | [1,2] | [4,8] |
| Уникальных k | 1000, `linspace` | 1000, `linspace` |
| Направлений на k | 8 | 8 |
| Всего FEM-полей | 8000 | 8000 |
| Train группы / поля | 670 / 5360 | 670 / 5360 |
| Val группы / поля | 170 / 1360 | 170 / 1360 |
| Test группы / поля | 160 / 1280 | 160 / 1280 |

Для частоты с `frequency_id=fid` используется воспроизводимый offset из RNG `[seed,fid,2]`; направления имеют вид `offset+2πj/8`. Все восемь направлений частоты принадлежат одному split. Группы частот переставляются с seed=2026 и fractions=(.67,.17,.16). В обеих полосах соответствующие `frequency_id` имеют одинаковое назначение split, хотя численные k различны.

Одна и та же среда во всех split — намеренное свойство задачи. Test оценивает удержанные частоты внутри полосы и их направления. Такое разбиение не является проверкой новых материалов или геометрии. Нельзя описывать 1000 частот как 1000 сред или требовать disjoint medium IDs от этой постановки. Frozen low-band → high-band отдельно проверяет частотный OOD.

## Пути и хранение

Данные: [low config](../data/static_low_frequency_1000x8/config.json), [high config](../data/static_high_frequency_1000x8/config.json); машинные сводки — [low dataset_info](../data/static_low_frequency_1000x8/dataset_info.json) и [high dataset_info](../data/static_high_frequency_1000x8/dataset_info.json).

`fem_dataset.npz` содержит A,n,A_cells,n_cells одной строкой. Loader выдаёт read-only broadcast views общего формата `[samples,nodes/cells]`; повторные материалы не занимают отдельную строку для каждого решения на диске. `u_scat` хранится явно как `complex128` по всем 8000 комбинациям `(k,θ)`. Фактическая сетка содержит 3221 узел и 6280 треугольников при h=0.1 и coarse grid 4×4; формы и mesh hashes проверены после генерации. В каталоге также сохраняются `geometry.npz`, physical cell tags и `etal.msh`.

Общий CLI выбирает `--pod-method full|randomized`. Full-профиль пишет в `runs/static_low_frequency_1000x8` / `runs/static_high_frequency_1000x8`, randomized — в `randomized/runs/low_frequency_static_1000x8` / `randomized/runs/high_frequency_static_1000x8`. Данные и физика общие; различается алгоритм POD. Повторяющиеся wrappers объединены в [общие notebooks](../notebooks/), для SVD-SNO оставлены [два варианта](../sno/). См. [структуру проекта](structure.md).

## Нулевой входной ранг и самостоятельный inference

Поскольку A,n постоянны по выборке, их центрированные матрицы снимков равны нулю. Корректный numerical rank равен нулю как для full, так и randomized POD. Нельзя сохранять noise modes и усиливать их нормировкой. Вход SVD-сети сокращается до трёх переменных `cos θ,sin θ,k`; средний материал хранится в bundle. Нулевые входные ранги не означают нулевой ранг выходных полей.

Smoke-проверки должны подтвердить поддержку нулевых рангов, размер входа 3, finite forward/loss и save/load single/batch inference. Эти тесты проверяют реализацию, а не точность полноценного обучения. Train-only output bases, val rank/checkpoint selection и consistent FEM L2 метрика сохраняются.

## Фактическая генерация и проверка

Обе полосы созданы локально и повторно прочитаны с диска. Полный протокол: [static_medium_validation.json](static_medium_validation.json).

| Набор | Полей / физических сред | u_scat | Архив, MiB | Генерация и сохранение, с |
|---|---:|---|---:|---:|
| static_low_frequency_1000x8 | 8000 / 1 | [8000, 3221] complex128 | 376.29 | 91.91 |
| static_high_frequency_1000x8 | 8000 / 1 | [8000, 3221] complex128 | 376.58 | 95.51 |

Подтверждены 1000 уникальных частот и 8 направлений на каждую, split 670/170/160 частот, отсутствие пересечений частот между splits и один medium_id=0. Коэффициенты на диске имеют shapes [1,3221] для A,n и [1,6280] для DG0, после загрузки — broadcast views. Каждая полоса содержит 3221 FEM-узел и 6280 треугольников.

Весь материал побитово совпал со средой 0 прежнего увеличенного variable-medium набора. Хеши A,n/DG0, geometry/connectivity, углов, frequency_id и split совпали между полосами; k и решения отличаются. После чтения архивов хеши всех массивов совпали с исходными.

Повторно решены шесть задач: по одной train/val/test в каждой полосе. Во всех случаях relative FEM L2 difference с сохранённой меткой равна 0; максимальный linear residual — 2.022e-14. Нулевые входные POD-ранги A,n подтверждены и на полном наборе.

Прошли 56 numerical/integration tests, включая фактический randomized range solver, нулевые входные ранги, gradient/backprop и portable inference. CLI randomized отдельно проверен на небольшом физическом наборе: генерация, две эпохи и bundle завершились успешно. Это smoke-проверка работоспособности, а не измерение точности полного обучения.

Каталоги full/randomized читают одинаковые данные и используют различные run paths; прежние variable-medium и pilot артефакты сохранены.

## Ограничение сетки

h=0.1 сохранён. В прежнем variable-medium pilot разница с уточнённой high-band FEM-сеткой составляла примерно 11–15%; она не измеряет ошибку новой фиксированной среды. Увеличение количества частот не исправляет дисперсионную ошибку FEM. Перед выводами о физической high-frequency точности нужна собственная проверка уточнением сетки. Старые pilot метрики и старое split-by-medium описание нельзя переносить на текущий frequency-split эксперимент.

## Память при локальном обучении

CLI обучения читает u_scat через read-only mmap. Первый запуск создаёт проверяемый по исходному архиву кэш NPY в .array_cache внутри каталога набора; повторный использует его. Проверки и хеширование идут по блокам без полного копирования broadcast-материалов. Randomized POD центрирует одну рабочую матрицу; для SVD loss не создаётся двухканальная копия всех FEM-целей — они читаются порциями. Метрика сохраняется consistent FEM L2, её Gram-форма проверена по значениям и градиентам относительно прямой интеграции.

## Обученные randomized модели

Две модели обучены локально на полных low/high наборах; средняя test FEM L2 составляет 0.96% и 5.54%. [Отчёт randomized](../randomized/RESULTS.md) содержит конфигурации, проекционные ошибки, частотный перенос и фактическое уточнение high-band сетки. Его результаты заменяют прежние предположения о ещё не выполненном обучении; root full-SVD и остальные методы остаются отдельными экспериментами.
