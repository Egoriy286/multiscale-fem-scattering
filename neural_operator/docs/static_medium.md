# Фиксированная физическая среда static-low

Текущий набор использует одну среду: геометрия включений, узловые A,n и поэлементные DG0-материалы неизменны. Меняются только параметры падающей волны `(k,θ)`, k∈[1,2].

`StaticDatasetConfig` задаёт `fixed_medium_id=0`, `seed=2026`, `active_range=(3,10)`, `a_range=(.6,.9)`, `n_range=(1.5,3.)`. Генератор воспроизводимо выбирает активные круги и контрасты один раз. Фон A=n=1; для всех снимков `medium_id=0`.

| Параметр | Значение |
| --- | --- |
| Частоты | 1000 уникальных k, равномерно на [1,2] |
| Направления | 8 на каждую частоту, с воспроизводимым угловым offset |
| FEM-поля | 8000 комплексных полей |
| Train | 670 частот / 5360 полей |
| Validation | 170 частот / 1360 полей |
| Test | 160 частот / 1280 полей |
| FEM-сетка | h=0.1; 3221 узел, 6280 треугольников |

Все направления одной частоты принадлежат одному split. Статистики, POD-базисы и веса обучаются по train; validation выбирает выходной ранг и checkpoint. Test оценивает удержанные частоты и направления той же среды. Это не проверка новых материалов или геометрии.

Набор находится в `neural_operator/data/static_low_frequency_1000x8`. В каталоге хранятся `config.json`, `fem_dataset.npz`, `geometry.npz`, `dataset_info.json` и `etal.msh`. Материалы сохранены одной строкой с read-only broadcast при загрузке. `u_scat` имеет форму `[8000,3221]`, dtype complex128; DG0-материалы заданы по 6280 ячейкам. Mesh connectivity и node ordering входят в fingerprint.

Поскольку A,n постоянны по выборке, их центрированные POD-ранги равны нулю. SNO получает только `cosθ,sinθ,k`; сохранённая модель не различает новые материалы. Выходные POD-базисы Re/Im при этом имеют ненулевые ранги.

Обучение читает поля через read-only mmap. Проверяемый NPY-кэш ускоряет повторные чтения и не заменяет исходный архив. Для SNO consistent FEM loss вычисляется через Gram-форму в выходных POD-координатах; значения и градиенты сопоставлены с прямой P1-интеграцией.

Актуальные runs: SNO v2 и Chebyshev в `neural_operator/runs/revision_2026-11-08/static_low/`, FNO в `neural_operator/randomized/runs/low_frequency_static_1000x8/fno`. [Метрики и происхождение](operator_revision.md) · [Данные и команды](datasets.md) · [Аудит](dataset_audit.md).

Ошибка относительно дискретного FEM reference не является оценкой ошибки непрерывной PDE. Другие диапазоны частот требуют собственного набора, проверки FEM-разрешения и отдельного каталога результатов.
