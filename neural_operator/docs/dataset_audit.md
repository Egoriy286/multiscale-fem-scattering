# Аудит активного датасета

В проекте оставлен один neural-датасет: **static_low_frequency_1000x8**. Это одна фиксированная среда, k∈[1,2], 1000 частот × 8 направлений = 8000 полей на 3221 FEM-узле и 6280 треугольниках. Split группируется по частотам: 5360/1360/1280 train/validation/test полей.

Устаревшие экспериментальные серии удалены целиком из локальных data/runs и текущих tracked материалов. Их отчёты, изображения и snapshots не сохраняются в отдельном архиве. Метрики оставшихся моделей и все 1280 их test-полей сохранены без изменения.

## Проверки

Потоковое чтение NPZ проверяет ZIP CRC, конечность значений, положительность материалов/частот и SHA256. Проверяются точные формы массивов, число FEM-узлов геометрии, индексы и невырожденность треугольников, размеры из recipe и непересечение групп между splits. Проверка не создаёт распакованный array cache.

[Машинный аудит](dataset_audit.json) содержит только текущий набор, его recipe, размеры и хеши. [Refinement](static_low_refinement.json) сохраняет выполненную выборочную проверку low-band: изменение при h→h/2 равно **0,6577%**, 3221→8958 DOF. Она не является сертификацией всех полей или оценкой точной PDE-ошибки.

Применён настраиваемый проектный порог выборочной FEM-разницы 2%. Статус `sampled_refinement_pass` означает прохождение имеющейся выборочной проверки. Отсутствие такой проверки не приравнивается к прохождению. Нейронная test-ошибка не используется для удаления отдельных примеров.

## Повторение

Из корня репозитория:

```bash
docker compose exec -T dolfinx-complex python3 -m neural_operator.datasets.curation \
  --root neural_operator/data \
  --evidence neural_operator/docs/dataset_audit_evidence.json \
  --threshold 0.02 --output /tmp/current_dataset_audit.json

docker compose exec -T dolfinx-complex python3 -m pytest neural_operator/tests/test_curation.py -q
```

Аудитор только читает данные и записывает новый JSON; автоматического удаления нет. Большие архивы обрабатываются блоками. Датасет и model bundles не входят в Git; команды генерации и обучения приведены в [neural README](../README.md).
