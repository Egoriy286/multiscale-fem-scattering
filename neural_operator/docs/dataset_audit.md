# Аудит и очистка датасетов — 8 ноября 2026

Проверены **все шесть имевшихся FEM-наборов**, а не только удачные модели.
Потоковое чтение каждого NPY payload проверило ZIP CRC, конечность значений,
положительность материалов и частот; отдельно проверены конфигурации,
размеры, связность треугольников, невырожденность элементов, counts и
непересечение групп train/validation/test. Для массивов с совпадающей
сохранённой формой сверены SHA256 из `dataset_info.json`.
Повреждений и split leakage не найдено.

Полный протокол **до очистки**, конфигурации, SHA256 архивов и массивов,
список удалений: [dataset_audit.json](dataset_audit.json).

Числа refinement взяты из сохранённых расчётов; аудит архивов не запускал
новую FEM-серию и не проверял каждый снимок повторным решением PDE.

У двух удалённых наборов не обнаружена порча. Причина удаления — устаревший
профиль, а не ошибка отдельного тестового примера. Их recipes и хеши остались
в протоколе и [историческом отчёте расширения](dataset_expansion.json).
Сохранённые pilot/static результаты и обученные `model.pt` не удалялись.

Суммарно удалено **1 236 589 779 байт ≈ 1,15 GiB**: два устаревших
каталога и пересоздаваемые `.array_cache` у pilot-low/static-high.
Распакованный массив static-low оставлен для текущего обучения.
Эти данные и кэши были локальными игнорируемыми артефактами; Git хранит
сам аудит, рецепты и результаты, но не полноразмерные neural-датасеты.

## Правило качества

В [curation.py](../datasets/curation.py) принят явно настраиваемый порог
выборочной разницы FEM **2%**. Это практический порог проекта, а не теорема
о точности PDE. `sampled_refinement_pass` означает прохождение только
имеющихся проверок, а не сертификацию всех меток. Отсутствие refinement даёт
`refinement_pending`; превышение порога — `stress_only`; порча/утечка —
`invalid_integrity`; устаревший целый recipe — `obsolete_recipe`.

Ошибка нейросети не участвует в решении об удалении. Нельзя исключать
трудные test-примеры и затем сравнивать новую среднюю со старой. Сначала
фиксируются recipe, split и критерий точности FEM, затем модели получают
один и тот же набор. Высокочастотная сетка требует новой общей генерации
и последующей h-серии; увеличение числа частот не исправляет дискретизацию.

## Повторная проверка оставшихся данных

Из корня репозитория:

```bash
docker compose exec -T dolfinx-complex python3 -m neural_operator.datasets.curation \
  --root neural_operator/data \
  --evidence neural_operator/docs/dataset_audit_evidence.json \
  --threshold 0.02 --output /tmp/current_dataset_audit.json

docker compose exec -T dolfinx-complex python3 -m pytest neural_operator/tests/test_curation.py -q
```

Команда аудита **только читает данные** и пишет отдельный JSON. Ненулевой
exit code означает нарушение целостности; статус `stress_only` записывается
в отчёт и не вызывает скрытого удаления. Исходный протокол очистки не
перезаписывается. Архив читается блоками, без загрузки многогигабайтных
массивов материалов и создания `.array_cache`.

Для восстановления удалённого recipe можно извлечь `config` из нужной
строки `dataset_audit.json`, сохранить в `config.json`, прочитать через
`neural_operator.datasets.load_config` и вызвать `generate_dataset`
с новым каталогом. Побитовые хеши нового расчёта зависят также от версий
FEM/Gmsh и платформы; сравнивайте их с протоколом, а не предполагайте совпадение.
