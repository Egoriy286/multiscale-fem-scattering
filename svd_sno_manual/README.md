# SVD-SNO. Как предсказать поле рассеянной волны

Пособие для студентов, знакомых с комплексными числами, матрицами и производными.
Готовый файл находится в `output/pdf/svd_sno_student_manual.pdf`.
Редактируемый комплект с готовыми рисунками лежит в `output/svd_sno_latex_sources.zip`.

## Чтение

В начале разбирается один треугольник эталонной сетки GMsFEM. Для трёх его вершин
сравниваются среднее поле, вклады POD-мод, прогноз и расчёт МКЭ.
Затем выводится слабая форма задачи рассеяния и строится взвешенный POD-базис.
Пример в базисе Чебышёва знакомит с исходным SNO. Две следующие главы показывают
проектную SVD-SNO v2, операторную запись её матриц и прогноз в узле по сохранённой модели. Глава с результатами
разбирает среднюю тестовую ошибку, медиану и наилучшую точность декодера.

После основного материала даны оценки устойчивости, границы применимости и
вариант метода с комплексным базисом. В конце есть справочник обозначений,
указатель файлов реализации и литература.

## Сборка

Из корня репозитория или из каталога, в который распакован архив, выполните

```sh
sh svd_sno_manual/build.sh
```

Скрипт запускает XeLaTeX трижды и сохраняет PDF в `svd_sno_manual/output/pdf/`.
Для сборки используются готовые рисунки из `assets/`. Нужны TeX Live с русским
языком Babel и пакетами из преамбулы `main.tex`, шрифты PT Serif, PT Sans,
STIX Two Math и моноширинный Menlo или DejaVu Sans Mono.

## Воспроизведение примеров

Следующие команды выполняются в Python-окружении проекта из корня репозитория.

```sh
python svd_sno_manual/build_notation_assets.py
python svd_sno_manual/check_sno_examples.py
python svd_sno_manual/mini_demo.py
python svd_sno_manual/build_assets.py
```

Основная серия — `experiments/reference_sno_gmsfem/`. В ней используются
сетка `gmsfem/meshes/reference_n20_h0p04.msh`, метки `data/low/` и
сохранённая модель `runs/low/model.pt` (два последних пути относительно
каталога серии). Эталон содержит 53 246 узлов и 105 690 треугольников.
Координаты и индексы вершин сверяются с `gmsfem/results/notebook/fields.npz`.

Для карт поля, мод, ошибок и весов модели использована палитра ParaView
Blue to Red Rainbow. Внутри каждого треугольника сначала интерполируется
узловая величина, затем её значение переводится в цвет. Каждая ячейка
карты матрицы окрашена по значению одного веса.
[Определение палитры в ParaView 5.13.3](https://raw.githubusercontent.com/Kitware/ParaView/v5.13.3/Remoting/Views/ColorMaps.json)

Первый скрипт повторяет прогноз на элементе 53227, проверяет действие веса
первого блока и строит карты для глав 1 и 5. Последний повторяет прогноз
снимка 940, рисует поля, спектры и ошибки для главы 7 и обложки.
Промежуточные значения записаны в `assets/notation_example.json` и
`assets/forward_trace.json`. Пути и хеши исходных данных приведены в
`assets/evidence.json`. Два коротких скрипта между ними проверяют алгебру
слоёв, свойства мод и функцию потерь.

Файл `QA.md` содержит результаты проверки редакции. После сборки `check_pdf.py`
проверяет текст, ссылки и геометрию PDF с помощью pypdf и pdfplumber.
Команда `python svd_sno_manual/package_sources.py` обновляет архив и его манифест.
