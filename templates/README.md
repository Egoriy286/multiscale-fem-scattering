# Учебные шаблоны: лабораторные 4 и 6

Эти работы вынесены из корня проекта, чтобы отделить подготовку сеток от
расчётов рассеяния. Исходные задания и геометрия сохранены.

| Шаблон | Что изучать | Окружение |
| --- | --- | --- |
| [Лабораторная 4](laba4/README.md) | Тонкая сетка, крупные блоки, `SubMesh`, метки границ | DOLFIN 2019, Gmsh, Meshio |
| [Лабораторная 6](laba6/README.md) | Перекрывающиеся окрестности крупных вершин и локальные метки | DOLFINx Complex; отдельно сохранён Legacy-вариант |

Оба варианта лабораторной 6 находят `../laba4/mesh.geo` относительно своего
файла, поэтому перенос не меняет геометрию. Из корня репозитория:

```bash
docker compose exec -T dolfinx-complex python3 templates/laba6/lr6.py --fine 4
```

Для лабораторной 4 рабочим каталогом должен быть `templates/laba4`:

```bash
docker run --rm --init -e OMP_NUM_THREADS=1 -e OPENBLAS_NUM_THREADS=1 \
  -v "$PWD":/workspace -w /workspace/templates/laba4 \
  mvt25/fenics-legacy:local python3 lr4.py
```

Последняя команда предполагает уже собранный локальный Legacy-образ;
основной `dolfinx-complex` не содержит классический `dolfin`. Результаты
генерируются при запуске и не служат тестом точности нейрооператоров.
После сеток переходите к [учебному маршруту GMsFEM](../gmsfem/docs/learning_path.md).
