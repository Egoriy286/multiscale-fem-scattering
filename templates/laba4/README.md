# Шаблон лабораторной 4: крупные блоки и подсетки

[lr4.py](lr4.py) строит треугольную сетку единичного квадрата из
[mesh.geo](mesh.geo), выделяет крупные квадраты и отмечает границы подсеток.
Это подготовка геометрических понятий для GMsFEM; уравнение рассеяния и
спектральный базис здесь не решаются. [Исходное задание](materials/README.md).

Параметры `n` и `fine` задаются в `mesh.geo`: число блоков равно `n*n`,
целевой шаг — `h=1/(n*fine)`. При `n=10` получаются 100 блоков.
`Coherence` объединяет общие точки и линии, поэтому мелкая сетка согласована
с крупными границами. Номер блока — `i+n*j`.

Для запуска нужны **классический DOLFIN 2019**, Gmsh, Meshio, NumPy и Matplotlib.
Основной контейнер DOLFINx не заменяет Legacy-окружение. Из корня проекта,
если локальный Legacy-образ уже собран:

```bash
docker run --rm --init -e OMP_NUM_THREADS=1 -e OPENBLAS_NUM_THREADS=1 \
  -v "$PWD":/workspace -w /workspace/templates/laba4 \
  mvt25/fenics-legacy:local python3 lr4.py
```

В собственном Legacy-окружении:

```bash
cd templates/laba4
python3 lr4.py
```

Скрипт читает файлы относительно текущего каталога. Gmsh создаёт `mesh.msh`,
Meshio преобразует его в `mesh.xml`, DOLFIN выделяет `SubMesh` для каждого
квадрата. `MeshFunction` границ ставит метку 1 только внешним рёбрам подсетки.

После запуска появятся:

- `results/blocks.pvd` — номера крупных блоков на всей сетке;
- `results/submeshes_2/submesh.pvd` — последовательность квадратных подсеток;
- `results/submeshes_2/facet.pvd` — соответствующая последовательность меток рёбер;
- `results/mesh.png` — мелкие треугольники и крупные линии.

PVD ссылается на соседние VTU-файлы: переносите каталог целиком.
Кадр последовательности — номер подсетки, а не физическое время.
Расчётные сетки и результаты исключены из Git и создаются при запуске.
Для окрестностей крупных вершин продолжайте с [лабораторной 6](../laba6/README.md),
для локальных задач — с [учебным маршрутом GMsFEM](../../gmsfem/docs/learning_path.md).
