# SVD-SNO для переменных материалов, частот и направлений

Запуск из корня репозитория после записи `data/complete.json`:

```sh
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=2 VECLIB_MAXIMUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python -u paper/operators_band_2026/svd/train.py
```

Файл `../data/queries.npz` задаёт все запросы и разбиение по средам. Для каждого размера 400, 600, 800, 1000 берутся первые соответствующие строки train. Каждая среда входит целиком. Используется фиксированная validation-выборка для выбора ранга и эпохи, а test используется для итоговой оценки выбранной конфигурации.

Модель прогнозирует `v = u_s/k` для положительных частот. Центрированные POD-базисы Re/Im строятся независимо на текущей train-выборке в согласованной P1 массовой норме. Входы сети содержат четыре train-стандартизованных параметра среды, cos/sin угла и train-стандартизованное k. Коэффициенты `v` масштабируются обучающими стандартными отклонениями. После POD-декодирования выход умножается на k, и рассеянное поле при k=0 равно нулю.

SVDSNO v2 использует ширину 48 и 4 блока. Кандидаты ранга на каждую компоненту — 24, 48 и 72. Для всех конфигураций фиксированы seed 2026, 300 эпох, batch size 64, AdamW с learning rate 0.002 и weight decay 0.00001, cosine scheduler с конечным шагом 0.00015. Количество весов при ранге r, ширине w и глубине d равно `d*(2*w*w+w+r*r)+8*w+2`.

При положительном k относительные массовые ошибки `u_s` и `v` совпадают. В обучении коэффициентная формула складывает квадрат ошибки коэффициентов и квадрат проекционного остатка. Тестовые значения дополнительно сравниваются с ошибкой восстановленных узловых полей в согласованной FEM-норме.

- `validation.csv` содержит все кандидаты, лучшие эпохи и отметки выбора.
- `summary.csv` и `cases.csv` содержат процентные ошибки выбранных моделей.
- `example.npz` содержит комплексное рассеянное поле модели на 1000 train-полях для первого тестового запроса с k=4.
- `runs/` содержит веса и POD-базисы для воспроизведения.

Для диагностики на частотах 0.001, 0.01 и 0.025 после обучения запустить
`PYTHONDONTWRITEBYTECODE=1 .venv/bin/python paper/operators_band_2026/svd/nearzero.py`.
Скрипт применяет выбранную по validation модель N=1000 и сохраняет `nearzero.csv`.
