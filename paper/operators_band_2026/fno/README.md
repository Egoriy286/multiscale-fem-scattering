# Обычный FNO для новых сред и частот

FNO работает на равномерной сетке 32×32. В каждом спектральном блоке
используются двумерное FFT, обучаемые комплексные матрицы на низких
модах, локальная линейная свёртка и GELU. Масштабированных ветвей нет.
На вход подаются координаты, k, компоненты направления, вещественная
и мнимая части падающей волны, четыре параметра среды и два поля
материалов. Поля материалов вычисляются из долей ячеек соответствующего
тега вокруг узлов МКЭ с последующим переносом на равномерную сетку.
Нормировки входа и поля определяются отдельно для каждого train-префикса.

Модель обучается предсказывать комплексное рассеянное поле, делённое
на k. При оценке билинейно переносим прогноз на узлы эталонной сетки
и умножаем на k. Обучение использует согласованную матрицу масс
эталонной сетки в представлении на равномерной сетке. Билинейный
перенос T даёт матрицу G=TᵀMT. Оптимальная проекция метки на этот
базис и квадрат её остатка учитываются в относительной норме каждого
примера. Для финальной validation/test оценки заново вычисляется
комплексная узловая FEM L²-норма с M и сверяется с оценкой через G.
Средние считаются по индивидуальным относительным ошибкам.

Архитектура выбирается только по validation по результатам двух
12-эпоховых прогонов на 1000 train-примерах. Для каждого размера
выбранная архитектура обучается с новой инициализации. После 50 эпох обучение продолжается до 110 эпох при улучшении
минимума validation-ошибки хотя бы на 1% относительно за последние
15 эпох. Двадцать эпох без нового минимума завершают обучение. Параметры
сохраняются на эпохе с минимальной validation-ошибкой. Вложенные
train-префиксы содержат первые 40, 60, 80 и 100 полных сред.
Число параметров учитывает обе вещественные компоненты каждого
комплексного коэффициента FFT.

Запуск из корня репозитория после появления `data/complete.json` и `data/nearzero.npz`:

```sh
VECLIB_MAXIMUM_THREADS=2 OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python -u -m paper.operators_band_2026.fno.run fit --epochs 110
VECLIB_MAXIMUM_THREADS=2 OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python -u -m paper.operators_band_2026.fno.run score
```

Замороженная модель с 1000 train-примеров также оценивается на шести
задачах с k=0.001, 0.01 и 0.025. Они используют те же входные нормировки,
билинейный перенос и узловую согласованную FEM L²-норму.
