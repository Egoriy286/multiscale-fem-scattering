# Рассеяние при фиксированной среде: три нейросетевых метода

[Исходник статьи](main.tex), [PDF](main.pdf), [протокол воспроизведения](REPRODUCIBILITY.md), [аудит](REVIEW.md).

Статья рассматривает одну фиксированную среду, частоты k∈[1,2] и три текущих метода. Общий набор содержит 8000 FEM-полей, 1000 частот и восемь направлений на частоту. Split выполняется по частотным группам: 5360/1360/1280 полей train/validation/test.

| Метод | Mean FEM L2, % | Median, % | p95, % | Max, % | Параметры |
|---|---:|---:|---:|---:|---:|
| SVD-SNO v2 | 0,9475 | 0,8671 | 1,6534 | 2,8962 | 4022 |
| FNO | 1,6599 | 1,6329 | 1,9505 | 2,2305 | 445010 |
| Chebyshev-SNO | 7,9364 | 7,6838 | 9,8811 | 11,1065 | 2426 |

Ошибки относятся к комплексному рассеянному полю в consistent FEM L2 относительно дискретных FEM-меток. Они не являются измеренной ошибкой непрерывной PDE. Сравнение использует один seed и разные ёмкости моделей; универсального ранжирования архитектур и коэффициента ускорения не заявляется.

Для SVD-SNO используются по десять выходных POD-мод Re/Im. Материальные входные ранги равны нулю, так как A,n одинаковы во всех примерах. Chebyshev-SNO использует 8×8 мод на сетке 32×32; средний оптимальный validation decoder floor составляет 7,6143%. Это ограничение текущего выходного представления сохранено явно.

Все модели показаны на одном запросе — первой позиции test-списка, выбранной до просмотра ошибок. Для Re/Im/Abs согласованы цветовые шкалы и шкалы ошибок трёх методов. Скрипт не выбирает отдельный выгодный пример для каждой модели.

Сборка и проверка из этой папки:

```sh
sh build.sh
python3 validate_paper.py
```

Для проверки нужны NumPy; для сборки — XeLaTeX и Computer Modern Unicode. Научное Docker-окружение проекта уже содержит Python-зависимости. [Команды](REPRODUCIBILITY.md) задают конкретные каталоги данных и весов. Страницы готового PDF дополнительно проверяются визуально; сведения об этом записываются в [актуальный отчёт](evidence/validation_report.json).

Структура:

- `main.tex`, `main.pdf` — текущая статья.
- `images/` — геометрия, две архитектурные схемы и три предсказания текущих моделей с provenance.
- `evidence/current_static_low/` — метрики, настройки, истории, geometry snapshot и хеши трёх выбранных запусков.
- `original/` — неизменённые предоставленные исходник и рисунок; они не используются как источник текущих результатов.

Предоставленные классы не изменены. Холст статьи — 205×290 мм. Предупреждение о внутреннем имени класса `sibjim` унаследовано от шаблона. После сборки и проверки служебные файлы удаляются командой `sh build.sh --clean`; текущие PDF, изображения и свидетельства сохраняются. Авторские реквизиты подачи в предоставленных материалах отсутствуют и не заполнены вымышленными данными.
