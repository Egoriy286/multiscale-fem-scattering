# Статья: POD, SNO, Chebyshev и FNO для рассеяния

Редакция 8 ноября 2026 года. [Статья PDF](main.pdf), [исходник](main.tex), [аудит](REVIEW.md), [проверяемые примеры и команды](REPRODUCIBILITY.md).

Статья разделяет три постановки: новые среды, удержанные частоты одного материала и выход за пределы обученной полосы. Исторические JAX-результаты сохранены по outputs, а существующие статические PyTorch-веса отделены от новой версии SNO v2. Большие ошибки пилота и неудачного частотного переноса включены явно.

| Серия | Средняя test FEM L2, % | Что оценивается |
|---|---:|---|
| Историческая JAX SVD-SNO | 6,4549 | 100 отложенных сред, 800 полей |
| Статическая low, legacy SVD-SNO | 0,9614 | 160 удержанных частот, 1280 полей |
| Статическая low, SVD-SNO v2 | 0,9475 | Те же данные и POD-ранг; отдельное новое обучение |
| Статическая low, FNO | 1,6599 | Те же 1280 test полей; существующие веса |
| Статическая low, Chebyshev-SNO | 7,9364 | Новое обучение, 8×8 мод; validation decoder floor 7,6143% |
| Статическая high, отдельная legacy SVD-SNO | 5,5375 | Другая обученная модель; точность к FEM-меткам |
| Low legacy SVD-SNO → static high, frozen | 144,1781 | Частотная экстраполяция |
| Архивный пилот новых сред, SVD / Chebyshev / FNO | 68,5807 / 70,6241 / 38,8387 | 32 поля восьми отложенных сред |

Разница 0,9614% и 0,9475% относится к одному seed и разному числу параметров; превосходство архитектуры не установлено. High-band FEM меняется на 13–14% при h=0,1→0,05: результат 5,5375% характеризует дискретные метки, а не подтверждённую физическую точность. Архивная pilot SVD-SNO из таблицы отличается от фактически доступного другого checkpoint с ошибкой 74,0115%; это расхождение разобрано в статье и аудите.

Сборка:

```sh
sh build.sh
python3 validate_paper.py
```

Нужны XeLaTeX, предоставленные классы, Computer Modern Unicode и NumPy для проверки. В научном Docker-окружении NumPy уже установлен; [команды](REPRODUCIBILITY.md). Сборка создаёт служебный `build/` и копирует результат в `main.pdf`. Каталог `build/`, `__pycache__/` и временные PNG не входят в комплект исходных материалов. Для их удаления после проверки:

```sh
sh build.sh --clean
```

Оригинальный переданный текст и рисунок в [original/](original/) не изменены. Предоставленные классы не изменены; `sibjima_preview.cls` устраняет принудительный dvips-драйвер только своим исходным отличием от журнального файла. Холст статьи задан как 205×290 мм. Предупреждение о внутреннем имени класса `sibjim` унаследовано от шаблона.
