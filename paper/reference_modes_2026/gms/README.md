# GMsFEM на общей тестовой выборке

Тонкая сетка h=0.04 содержит 17 549 комплексных степеней свободы.
Крупная сетка 20×20 содержит 441 вершину. Для обоих типов GMsFEM
используются вложенные первые 4, 8 и 16 локальных мод, то есть
1 764, 3 528 и 7 056 комплексных степеней свободы соответственно.
Type 1 использует эллиптическое продолжение, Type 2 — продолжение
Гельмгольца. Пространство Type 1 общее для всех частот, пространство
Type 2 строится отдельно для каждой частоты. Факторизации глобальных
систем переиспользуются для восьми направлений при фиксированном k.

Запуск из корня репозитория после подготовки манифеста запросов:

```sh
paper/reference_modes_2026/gms/reproduce.sh calculate
paper/reference_modes_2026/gms/reproduce.sh score
```

Второй шаг выполняется после появления маркера `data/complete.json`.
Можно запустить оба шага командой `paper/reference_modes_2026/gms/reproduce.sh`
после готовности FEM. Оценка также сохраняет поле Type 2 M=16
для строки 192 в `example.npz` на эталонной сетке.
Промежуточные решения сохраняются по частотам для возобновления
прерванного расчёта.

Оценка для каждой задачи — относительная комплексная L²-ошибка
рассеянного поля в процентах. Сначала поле тонкой сетки вычисляется
в узлах эталонной сетки h=0.02, затем используется полная согласованная
P1-матрица масс именно этой эталонной сетки. Эта конвенция совпадает
с оценкой SNO. В `verification.json` приведена контрольная разница
с прямой квадратурной оценкой поля тонкой сетки, а также независимое
воспроизведение одной fine-, reference- и Type 2 M=16-задачи через
UFL-сборку.
