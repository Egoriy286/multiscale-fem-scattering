# Рассеянное поле на эталонной сетке

[Статья в PDF](main.pdf) · [Исходник LaTeX](main.tex) · [Таблица SNO](sno_summary.csv) · [Таблица GMsFEM и МКЭ](gms/summary.csv)

## Состав опыта

Для 157 различных волновых чисел решены по восемь задач с плоской падающей волной. Углы фиксированы, меняется частота. Во всех расчётах используется notebook-среда с 24 круговыми включениями. Эталонная P1-сетка совпадает с `gmsfem/meshes/reference_n20_h0p04.msh`, SHA256 `9273efc7c0b500209ff847de4ee36d3790b93d64b09e67f62348318ed6b6cb47`.

- `data/queries.npz` содержит частоты, углы в радианах, идентификаторы частот и разбиение по строкам (0 для обучения, 1 для валидации, 2 для теста). Планировщик использует начальное число 20261122.
- `data/fields.npy` хранит 1 256 заново рассчитанных комплексных рассеянных полей по 53 246 значений, в порядке строк запросов. В `data/reference_problem.npz` лежат координаты, треугольники и коэффициенты среды.
- Сначала идут 128 валидационных и 128 тестовых строк, далее 1 000 обучающих. По первым 400, 600, 800 и 1 000 обучающим строкам построены отдельные базисы. Сигнатуры данных, настройки девяти обучений и версии библиотек указаны в [протоколе](experiment.json).
- [Ошибки SNO по задачам](sno_cases.csv) и [ошибки GMsFEM по задачам](gms/per_case.csv) сопоставляются по ключам `row` и `index`. Значения `k` и `theta` совпадают. В обоих случаях знаменатель есть согласованная P1-норма комплексного эталонного рассеянного поля.
- Для SNO сохранены веса лучшей по валидации эпохи, две матрицы мод и обучающие масштабы в `runs/`. Для GMsFEM локальное число мод варьируется независимо от сетки, [здесь приведены численные проверки](gms/verification.json).

## Воспроизведение

Команды выполняются из корня проекта. Генерация МКЭ и расчёт GMsFEM используют запущенный сервис Docker Compose проекта. SNO обучается в локальном окружении Python на CPU. Большие бинарные данные сохраняются в каталоге статьи локально.

```sh
docker compose up -d dolfinx-complex
docker compose exec -T dolfinx-complex python3 paper/reference_modes_2026/generate.py
VECLIB_MAXIMUM_THREADS=4 OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=2 .venv/bin/python paper/reference_modes_2026/study.py
paper/reference_modes_2026/gms/reproduce.sh
.venv/bin/python paper/reference_modes_2026/figures.py
```

Для сборки статьи достаточно исходника и готовых подкаталогов `tables` и `figures`. Использованы XeLaTeX, русский модуль babel и шрифт Computer Modern Unicode из TeX Live.

```sh
cd paper/reference_modes_2026
latexmk -xelatex -halt-on-error -outdir=build main.tex
cp build/main.pdf main.pdf
```

Повторный запуск на завершённых данных проверяет контрольные суммы, загружает веса и пересчитывает все тестовые ошибки. В скрипте обучения прямая реконструкция по узлам проверяется для всех девяти конфигураций. Отдельно для модели с 400 обучающими полями значения на всех 128 тестах сверены с поэлементным интегрированием. Для GMsFEM одна задача повторена с независимой UFL-сборкой. Правило усреднения в статье даёт всем 128 полям одинаковый вес. Число независимых тестовых частот равно 16.
