# GMsFEM для новых сред

Тестовая выборка содержит 16 новых физических сред и восемь направлений
на среду при k=2. Включения с тегами 2 и 3 имеют параметры alpha1 и n1,
включения с тегом 4 имеют параметры alpha2 и n2. В фоне alpha=n=1.

Для каждой среды пространства Type 1 и Type 2 строятся заново на тонкой
сетке h=0.04 (17 549 комплексных степеней свободы). На крупной сетке 20×20
используются вложенные первые 4, 8 и 16 мод на вершину: 1 764, 3 528 и
7 056 комплексных степеней свободы. Одна факторизация каждой системы
применяется к восьми правым частям. Полное решение P1 на h=0.04 служит
дополнительной численной оценкой.

Ошибка измеряется тем же способом, что для SNO. Поле вычисляется в узлах
эталонной P1-сетки h=0.02, а для относительной комплексной нормы
рассеянного поля используется её согласованная матрица масс.

Команды из корня репозитория после создания `data/queries.npz`:

```sh
docker compose exec -T -e OPENBLAS_NUM_THREADS=1 -e OMP_NUM_THREADS=1 dolfinx-complex \
  python3 -u -m paper.variable_media_2026.gms.run calculate
docker compose exec -T -e OPENBLAS_NUM_THREADS=1 -e OMP_NUM_THREADS=1 dolfinx-complex \
  python3 -u -m paper.variable_media_2026.gms.run score
```

Оценка запускается после записи `data/complete.json`. Стадия `all`
выполняет расчёт и оценку одной командой. Промежуточные решения в
`.array_cache` используются для возобновления расчёта. Для проверки
трёх тестовых сред системы МКЭ пересобираются через UFL, после чего
заново решаются обе редуцированные задачи с 16 модами, полная задача
на h=0.04 и эталонная задача на h=0.02.
