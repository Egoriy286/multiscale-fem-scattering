4. Что будет при переносе low-модели на k > 2

Модель SNO high обучена внутри [2,4]. Замороженная SNO low обучена только внутри [0.1,2]. Эти прогнозы не следует смешивать.

У low-модели намеренно отдельная цветовая шкала, чтобы её большая ошибка не скрыла структуру эталонного поля и high-модели.

Источник — сохранённые test-задачи. SNO: замороженные checkpoint; GMsFEM: 20×20, Type 2, 16 локальных мод. Все поля сначала вычислены из своих исходных P1-сеток на общей сетке отображения 401×401; модуль взят после комплексной интерполяции. Проценты взяты из исходной FEM-квадратуры и независимо воспроизведены. Цветные карты не задают новые входные данные и не запускают обучение.
