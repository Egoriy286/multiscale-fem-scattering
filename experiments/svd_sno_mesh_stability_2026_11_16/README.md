# Сеточная устойчивость multiscale SVD-SNO — 16 ноября 2026

Изолированное исследование на трёх native CG2-сетках. Геометрия материальных интерфейсов одинакова с точностью сравнения координат 1e-12: проверены все 6144 сегмента и пары прилегающих материалов. Внутренние треугольные сетки независимо построены и не являются вложенными.

| Уровень | Заданный h снаружи / внутри включений | Комплексные FEM DOF |
|---|---|---:|
| 0 | 0.08 / 0.01 | 80545 |
| 1 | 0.04 / 0.005 | 167925 |
| 2 | 0.02 / 0.0025 | 519149 |

Основная серия: одни и те же 1000 train, 200 validation и 200 test на всех уровнях, k=0.05–20, фиксированная среда и направление. Повторно используются только физические параметры прошлого исследования, а все CG2-метки решаются заново. Test уже исследовался ранее; это проверка согласованности по сетке, а не новая слепая оценка обобщения.

Каждая сетка имеет собственные native коэффициенты CG2 и согласованную mass-матрицу. Поля хранятся complex128. POD строится независимо только по train. Ранг фиксирован 192, ширина 8, глубина 4 и восемь масштабных ветвей; при недостаточном численном ранге эксперимент останавливается. Три seed: 11,29,47. Все модели обучаются с нуля с одинаковой ёмкостью, максимум 1000 эпох, batch100, Adam lr0.001, weight_decay0.0001, cosine по шагам; checkpoint выбирается по validation, каждые пять эпох, patience40 проверок. Предобученные веса прошлого эксперимента здесь не используются.

Сравниваются физические поля на общей квадратуре, а не коэффициенты разных POD-базисов: их фазы и повороты могут различаться. Отдельно сохраняются FEM-погрешность, POD-остаток и ошибка нейросети относительно собственных FEM-меток. Для всех 200 test независимо вычисляется native CG3-эталон на средней сетке. Простая интерполяция старых предсказаний не считается новым обучением или проверкой сеточной устойчивости.

Критерий основной серии: на двух последних сетках средняя индивидуальная относительная разница предсказаний не более 1% для каждого парного seed; изменение средней тестовой ошибки относительно одного и того же CG3-эталона не более 0.25 процентного пункта. Знаменатель разницы предсказаний — норма предсказания на более мелкой сетке. Дополнительно публикуются P95 и максимум. Это эмпирический критерий, а не доказанная равномерная оценка. Квадратура проверяется повышением её порядка. Если расхождение аудита превышает 1e-4 в относительной норме (0.01 процентного пункта), прохождение проверки устойчивости не подтверждается.

Пилот k=4,10,20 выполнен. На k=20 различие native FEM между уровнями 0→1 составляет 5.40%, 1→2 — 0.50%. Эти числа пока ничего не говорят об устойчивости обученной сети.

1400 первичных запросов находятся в queries.json. Ещё 1000 обучающих запросов зарезервированы в confirmation_queries.json: серия с 2000 train допускается только после прохождения основной проверки, с повторным train-only POD. Непрохождение критерия сохраняется в отчёте, порог после просмотра результатов не меняется.

Воспроизведение из корня репозитория:

```sh
# В complex Docker, последовательно для LEVEL=0,1,2:
python3 -m experiments.svd_sno_mesh_stability_2026_11_16.physics generate --level LEVEL --manifest experiments/svd_sno_mesh_stability_2026_11_16/queries.json
python3 -m experiments.svd_sno_mesh_stability_2026_11_16.reference --root experiments/svd_sno_mesh_stability_2026_11_16
# Native macOS с MPS, после запуска генерации:
VECLIB_MAXIMUM_THREADS=2 OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 .venv/bin/python -u -m experiments.svd_sno_mesh_stability_2026_11_16.run all
.venv/bin/python -m experiments.svd_sno_mesh_stability_2026_11_16.run status
```

run all ждёт готовности данных, фиксирует хеши, выполняет девять обучений, replay и отчёт. До появления итогового отчёта серия считается незавершённой. Большие массивы, сетки и checkpoints хранятся локально и исключены из Git.
